🛰️ Oráculo — Arquitetura de Sistema

Diagrama técnico do fluxo de dados e da separação público × privado. Os pontos em movimento são os dados fluindo entre os serviços; as cores indicam o tipo de fluxo (push manual, agente, dispatch, API, cron).

Fluxos de atualização

Push manual (você → GitHub) Agente Claude (edita/commita código + seed do banco) Claude dispatch (dispara o workflow) API / RSS ao vivo (Asana · Supabase · News) Cron agendado (5h20/dia)

Camada de segurança

🔒 Auth + RLS (Supabase)

Login por e-mail e Row Level Security em todas as tabelas: política auth.uid() = user_id. Sem sessão válida, ninguém lê seus dados — nem com a chave pública.

🔑 Secret criptografado

O ASANA_TOKEN vive nos GitHub Secrets (criptografado), injetado só na execução do robô. Nunca aparece no código.

🌐 Público × Privado

A ilha (pública) não tem nenhum dado financeiro. Os números ficam só no Supabase privado, atrás de login. Repo com histórico limpo.

🔐 HTTPS ponta a ponta

GitHub Pages, Lovable, Supabase e todas as APIs por HTTPS. Backups sensíveis isolados fora do que é publicado.
